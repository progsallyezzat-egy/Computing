💡 Etymology & Definition

What is Pseudocode?

Pseudo means "not real" or "not genuine". Code means computer statements. Pseudocode translates to "not real program statements"! It sits comfortably halfway between human thinking (everyday English / flowcharts) and rigid computer syntax (like Python or C++).

</>
🌐

Language Independent

Anyone who knows any programming language (Python, Java, C++, or JavaScript) can read pseudocode and translate it to their preferred system.

🕊️

No Rigid Syntax

No compiler syntax errors! You don't fail for forgetting a colon (:) or exact uppercase letters. Just keep your style consistent throughout your program.

🤝

Collaborative Planning

Acts like an essay outline. Teams use it to agree on variables, loops, and math calculations before sitting down to write formal high-level code.

Terminal (Start/Stop)

In pseudocode, some people write explicit words like START and STOP (or BEGIN / END). In modern curriculum practice, we write ordered statements top-to-bottom without start/stop keywords to closely match languages like Python.

Variable Identifier Rules (Page 21)

's Tips

A variable is a named location in computer memory storing one piece of data. Test identifier validity below:

✓ Single word: No spaces allowed (use CamelCase or underscores: totalScore, num_days).
✓ No initial digits/symbols: Cannot start with numbers (2ndValue is invalid; use value2).
✓ Not a Reserved Word: Cannot be language keywords like if, while, INPUT, print.
✓ Consistent format: Don't alternate between Total, total, and TOTAL in the same algorithm.

String Concatenation (Page 18)

Joining Strings

Concatenation is joining two or more text strings together. For instance, "Foot" + "ball" becomes "Football". In pseudocode, you can use comma (,), ampersand (&), or plus (+).

// Pseudocode expression:

Observe how the exact same program (adding two user numbers) transitions across all three representations: from visual graphical shapes to language-agnostic pseudocode, and ultimately to runnable Python syntax.

Best for visualizing control flow & branch pathways before writing any statements.

2. Pseudocode

INPUT num
INPUT num2
answer ← num + num2
OUTPUT answer
Language Independent: Written in clear English terms without worrying about colons, parentheses, or data conversion types.

3. Python (High-Level)

num = int(input())
num2 = int(input())
answer = num + num2
print(answer)
Strict Syntax Required: Notice how Python requires explicit type casting with int(), exact parentheses, and precise lowercase words.
